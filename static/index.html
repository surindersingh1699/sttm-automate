Decoder toggles

All four flip the model live — no reload needed. Changes persist across restarts.

Greedy
beam_size: 5 → 1. 3–5× faster per window; minor accuracy hit. Try if RTF is consistently slow.
Single-pass
temperature: [0.0]. Skips Whisper's 6-step fallback loop (0.0 → 0.2 → … → 1.0) that fires when compression-ratio / logprob gates fail. Removes worst-case latency spikes. On by default.
Allow repetition
compression_ratio_threshold: 2.4 → 10.0. Kirtan repeats lines on purpose; the default trigger treats that as a hallucination and retries. Off = retries, on = trusts the output. On by default.
Independent windows
condition_on_previous_text: false. Stops Whisper from carrying the last window's text as context. Helps when a bad transcription poisons subsequent windows; slight quality loss on clean audio.
Cap decode length
max_new_tokens: 128. Hard upper bound on tokens generated per window. Prevents the decoder from running off into long hallucination loops when "Allow repetition" is on. Safety net — keep on. On by default.
Skip slow windows
Drop any window whose RTF > 2.0. Slow decodes are usually garbled/repetitive. When tripped, the window is thrown away (no match update, no line-align, no challenger). Keeps the current lock stable instead of letting junk poison it. On by default.
